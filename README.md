# NCS Trash Valet Site

Local marketing site for `Nexus Cleaning Solutions`.

## Run

```bash
npm install
npm run dev
```

## Update Fast

- Main business content: `src/data/siteContent.js`
- Styles: `src/styles.css`
- Home page: `index.html` + `src/home.js`
- Service details: `services.html` + `src/services.js`
- Service area: `coverage.html` + `src/coverage.js`
- Legal pages: `privacy.html`, `terms.html`

## Inquiry Form

- Live option: `FormSubmit` browser form
  - Posts directly to `texas.ncs@gmail.com`
  - Better browser UX than `mailto:`
